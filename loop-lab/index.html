This is your whole song written as code. Export saves it as a file and Copy puts it on your clipboard. To bring a song in, paste its code here and press Load this code, open a saved file, or drag a file onto the page. Every song on the Coded Music site has an Open in Loop Lab button and a Copy Loop Lab code button. Sounds you upload aren't part of the code, so add them again after loading.
